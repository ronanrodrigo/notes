# 23/07/2026 - Self-host IA: Coolify, agentes e RAG

## Coolify

Self-host de apps (estilo Heroku/Vercel) com deploy via Git e auto-deploy. [Source](https://coolify.io/docs/applications/ci-cd/github/overview)

https://coolify.io/docs/applications/ci-cd/github/overview

## OpenHands

Agentes para desenvolvimento de software que planejam e executam mudanças no códigobase (controle por CLI/SDK). [Source](https://github.com/OpenHands/OpenHands)

https://github.com/OpenHands/OpenHands

## Open WebUI

Interface web "estilo ChatGPT" self-hosted para rodar localmente e conectar a modelos (inclui endpoints OpenAI-compatible e Ollama). [Source](https://github.com/open-webui/open-webui)

https://github.com/open-webui/open-webui

## Maxun

Plataforma no-code/open-source para extrair dados da web e transformar em dados estruturados/formatos como API/Markdown. [Source](https://github.com/getmaxun/maxun)

https://github.com/getmaxun/maxun

## Browser Use

Framework open-source para automação web por agentes (IA controlando navegação para executar tarefas online). [Source](https://github.com/browser-use/browser-use)

https://github.com/browser-use/browser-use

## Langflow

Editor visual open-source para orquestrar LLMs/fluxos (RAG e agentes) e expor como API. [Source](https://github.com/langflow-ai/langflow)

https://github.com/langflow-ai/langflow

## Supabase

Backend tipo Firebase, mas em Postgres: Auth, Storage, Realtime e APIs automáticas (base para backends de apps). [Source](https://supabase.com/docs)

https://supabase.com/docs

## Stirling PDF

Plataforma self-hosted open-source para editar/manipular PDFs (merge, split, OCR etc.) rodando localmente via Docker. [Source](https://github.com/Stirling-Tools/stirling-pdf)

https://github.com/Stirling-Tools/stirling-pdf

## Crawl4AI

Crawler/scraper open-source "LLM-friendly" para gerar Markdown limpo e/ou extração estruturada em pipelines de RAG. [Source](https://github.com/unclecode/crawl4AI)

https://github.com/unclecode/crawl4AI

## Dify

Plataforma open-source para criar apps/agentes com workflows visuais, RAG e publicação via API; auto-hospedável. [Source](https://github.com/langgenius/dify)

https://github.com/langgenius/dify
