# 23\/07\/2026 - Trilhas e cursos de IA (OpenAI, DeepLearning.AI, Anthropic, Google, Make, n8n)

## OpenAI Academy Courses
Trilhas de aprendizagem prática da OpenAI para ganhar fluência em IA, com foco em tarefas do trabalho, instruções claras e workflows com agentes.

https:\/\/academy.openai.com\/pages\/courses

## ChatGPT Prompt Engineering for Developers
Curso curto para aprender técnicas de prompt engineering e como aplicar LLMs em aplicações (com exemplos e atribuição\/grading para PRO).

https:\/\/www.deeplearning.ai\/courses\/chatgpt-prompt-eng

## Claude 101
Curso oficial para aprender a usar o Claude em tarefas do dia a dia, entender recursos principais e seguir para tópicos mais avançados.

https:\/\/anthropic.skilljar.com\/claude-101

## AI Fluency: Framework & Foundations
Curso para colaborar com sistemas de IA de forma eficaz, eficiente, ética e segura; inclui avaliação final e certificado.

https:\/\/anthropic.skilljar.com\/ai-fluency-framework-foundations

## Building with the Claude API
Curso técnico para aprender a usar o Claude via API (com tópicos como prompt engineering, tool use, RAG e agentes), com exercícios e certificado.

https:\/\/anthropic.skilljar.com\/claude-with-the-anthropic-api

## Claude Code 101
Curso para usar o Claude Code no fluxo de desenvolvimento, incluindo conceitos de agentic loop, contexto, ferramentas\/permiteções e práticas com instalações e configuração.

https:\/\/anthropic.skilljar.com\/claude-code-101

## Make Academy
Plataforma de aprendizado com cursos hands-on e learning paths para automação e trilhas de IA\/agentes (com badges digitais).

https:\/\/academy.make.com\/

https:\/\/learn.n8n.io\/courses

https:\/\/www.elementsofai.com\/
