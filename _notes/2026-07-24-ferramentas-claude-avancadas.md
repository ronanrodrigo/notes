## Graphify - Transformar Codebase em Grafo de Conhecimento
Ferramenta open-source (MIT license) que transforma código, docs, PDFs, imagens e vídeos em um grafo de conhecimento consultável. Usa tree-sitter para análise local (sem LLM) e extração semântica opcional para documentação não-code.

[Acesse aqui](https://github.com/Graphify-Labs/graphify)

## Graphify: Deep Dive Técnico 2026
Relatório técnico completo sobre o Graphify (Y Combinator S26), uma ferramenta open-source que converte qualquer codebase em um grafo consultável, evitando rereading de arquivos e economizando tokens de contexto.

[Acesse aqui](https://www.devshelfhub.com/articles/graphify-knowledge-graph-ai-codebase/)

## Vídeo Tutorial: Graphify para Claude Code
Demonstração prática de como instalar e usar o Graphify como skill em assistentes de IA, mostrando como mapear um projeto inteiro em um grafo de conhecimento consultável em segundos.

[Acesse aqui](https://www.youtube.com/watch?v=AkP7-uBB7hc)

## Graphify: Skill para Assistentes IA
Explicação de como o Graphify funciona como skill em Claude Code, Cursor e outros assistentes, utilizando parsing com tree-sitter (local, determinístico, sem LLM) e enriquecimento semântico opcional para mídias.

[Acesse aqui](https://dev.co/ai/rag/graphify)

## Graphify.net - Site Oficial
Site oficial do Graphify apresentando a ferramenta como construtor de grafos de conhecimento para assistentes de IA, combinando análise estática com tree-sitter e extração semântica orientada por LLM.

[Acesse aqui](https://graphify.net/)

## Impeccable - Framework de Skills de Design
Toolkit de habilidades de design construído especificamente para ferramentas de codificação com IA, com 23 comandos de design e 45 detectores de anti-padrão.

[Acesse aqui](https://moge.ai/br/product/impeccable)

## Video Toolkit - Skill Claude Code para Análise de Vídeos
Skill especializada para Claude Code designada para processamento abrangente de vídeos e análise multi-modal diretamente no seu ambiente de desenvolvimento.

[Acesse aqui](https://mcpmarket.com/tools/skills/video-toolkit)

## Video Insight - Transcrição e Análise de Vídeos
Utilitário especializado para Claude Code que transforma conteúdo audiovisual de URLs do YouTube ou arquivos locais em documentação de alta qualidade, automatizando extração de transcrições e gerando resumos, Q&A e seções de pesquisa profunda.

[Acesse aqui](https://mcpmarket.com/tools/skills/video-insight)

## graphify-rs - Construtor de Grafos em Rust
Versão em Rust do construtor de grafos de conhecimento (cargo install graphify-rs) que permite criar grafos a partir de código, documentos e imagens, com suporte a extração semântica via LLM.

[Acesse aqui](https://docs.rs/crate/graphify-rs/latest)
