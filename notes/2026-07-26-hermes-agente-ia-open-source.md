# 26/07/2026 - Hermes: Agente IA Open Source com Memória Persistente

## Hermes Agent - Documentação Oficial

Agente IA autônomo open source desenvolvido pela Nous Research (MIT License) que funciona 24/7 em seu servidor. Possui memória persistente, criação automática de skills, suporte a múltiplas plataformas (Telegram, Discord, Slack, WhatsApp) e aprende com o tempo.

[Acesse aqui](https://hermes-agent.nousresearch.com/)

## Repositório GitHub - NousResearch/hermes-agent

Código-fonte oficial do Hermes Agent no GitHub. Contém documentação completa, guias de instalação para Linux, macOS, WSL2 e Docker, além de exemplos de uso.

[Acesse aqui](https://github.com/nousresearch/hermes-agent)

## Hermes AI - Documentação e Guia Rápido

Portal de documentação com tutoriais passo a passo para instalação, configuração, uso da CLI e interface terminal (TUI). Inclui requisitos do sistema (64k context window) e opções de LLM (Claude, GPT, Gemini, OpenRouter).

[Acesse aqui](https://hermes-ai.net/)

## YouTube - Hermes Agent Overview (Nous Research)

Vídeo explicativo mostrando todas as funcionalidades: integração com Telegram, Discord e Slack, análise de imagens, busca na web, execução de código, instalação de Skills, Learning Loop e suporte a modelos locais.

[Acesse aqui](https://www.youtube.com/watch?v=jIP0q7HEC0g)

## YouTube - Hermes: El Agente IA Open Source Más Potente

Tutorial em espanhol demonstrando instalação em VPS, Raspberry Pi e PC pessoal. Mostra como configurar para rodar 24/7, integração com plataformas de mensagens e comparação com outras ferramentas similares.

[Acesse aqui](https://www.youtube.com/watch?v=YR-4vFbwe18)

## YouTube - Hermes es BRUTAL - Guía Completa

Guia completo em espanhol sobre como ter um assistente IA 24/7 instalado em servidor próprio. Cobre instalação, configuração, acesso via mobile e uso como membro do time de trabalho.

[Acesse aqui](https://www.youtube.com/watch?v=LcTJuN0drAo)

## Hermes Agent CLI - Implementação em Rust

Reescrita nativa do Hermes Agent em Rust com suporte first-class para Windows. Ferramenta de linha de comando para chat com qualquer LLM, execução de ferramentas e gerenciamento de sessões.

[Acesse aqui](https://lib.rs/crates/hermes-agent-cli)
