O Notes é um site estático de leitura pública e não possui cadastro, login, comentários, formulário de contato próprio nem API de escrita. A navegação pelas notas não exige identificação e nenhum dado pessoal é solicitado em nenhuma página deste site.

Para entender o uso agregado das páginas, o site utiliza medição de acesso via Google Analytics (GA4, identificador G-0TE9HBV804) e Firebase Analytics no site pessoal associado. Essas ferramentas podem registrar dados técnicos de navegação, como páginas visitadas, tipo de dispositivo, navegador e região aproximada, segundo as políticas do Google. O conteúdo das notas é hospedado no GitHub Pages, que pode registrar logs técnicos de entrega das páginas.

Não há compartilhamento de dados com terceiros além desses processadores de medição e hospedagem, e nenhum dado é vendido ou usado para publicidade própria. Links para serviços externos (perfis, fontes citadas nas notas, canais de contato) seguem as políticas de privacidade de cada serviço.
