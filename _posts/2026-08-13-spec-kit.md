## Spec Kit no GitHub

O Spec Kit é um toolkit open source do GitHub para desenvolvimento orientado por especificações. Ele propõe definir o que será construído antes de codificar e organiza o trabalho em etapas que podem ser usadas com diferentes agentes de programação.

[Acesse a fonte original](https://github.com/github/spec-kit)

## Visão geral do Spec Kit

A documentação apresenta o fluxo padrão como **Spec → Plan → Tasks → Implement**. Cada fase produz um artefato em Markdown que serve de contexto para a seguinte, com templates, checklists e análise entre os artefatos.

[Leia a visão geral oficial](https://github.github.io/spec-kit/)

## Guia de instalação do Specify CLI

O `specify-cli` é a interface de linha de comando do projeto. O guia oficial cobre instalação com `uv`, `pipx` ou `pip`, inicialização de um projeto e verificação da instalação com `specify version`.

[Consulte o guia de instalação](https://github.github.io/spec-kit/installation.html)

## Integrações com agentes de programação

O Specify CLI prepara os arquivos de comandos ou skills para o agente escolhido. A documentação lista integrações para ferramentas como Codex, Claude Code, GitHub Copilot, Gemini, Kilo Code e Zed, entre outras.

[Veja as integrações suportadas](https://github.github.io/spec-kit/reference/integrations.html)
