## Anthropic Skills

Repositório público oficial com skills de exemplo para aplicações criativas, tarefas técnicas, fluxos corporativos e os skills de documentos que alimentam as capacidades nativas do Claude. Serve tanto como ponto de partida quanto referência de padrões bem construídos de `SKILL.md`.

[Consulte o repositório oficial](https://github.com/anthropics/skills)

## Superpowers

Framework de skills e metodologia completa de desenvolvimento de software para agentes: brainstorming, planos detalhados, TDD red/green obrigatório, desenvolvimento orientado a subagentes e revisão de código entre tarefas. Funciona no Claude Code via marketplace de plugins e em outros agentes.

[Explore o framework](https://github.com/obra/superpowers)

## Karpathy-Inspired Guidelines

Um único arquivo `CLAUDE.md` derivado das observações de Andrej Karpathy sobre erros comuns de LLMs ao programar: pensar antes de codificar, simplicidade primeiro, mudanças cirúrgicas e execução orientada a objetivos com verificação.

[Leia as diretrizes](https://github.com/multica-ai/andrej-karpathy-skills)

## Skills for Real Engineers

Skills práticas que Matt Pocock usa no próprio dia a dia de engenharia, extraídas diretamente do diretório dele: design de codebase, triagem, testes e disciplina de engenharia aplicada a agentes.

[Veja as skills do Matt Pocock](https://github.com/mattpocock/skills)

## UI UX Pro Max Skill

Skill de inteligência de design para agentes construírem interfaces profissionais: dezenas de estilos de UI, centenas de paletas de cores, pares tipográficos, guidelines de UX e stacks suportadas em web e mobile.

[Conheça o skill de design](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

## caveman

Skill para Claude Code que reduz drasticamente o uso de tokens de saída ao forçar respostas curtas e diretas — "why use many token when few token do trick". Benchmarks do projeto apontam cerca de 65% de economia média, preservando precisão técnica.

[Teste o caveman](https://github.com/JuliusBrussee/caveman)

## Agent Skills do Addy Osmani

24 skills de engenharia de nível produção cobrindo o ciclo completo de desenvolvimento, com portões de verificação, anti-padrões e workflows que seniores seguem — empacotados para agentes seguirem de forma consistente.

[Navegue pelas 24 skills](https://github.com/addyosmani/agent-skills)

## Taste Skill

Skills anti-slop para frontend: impedem que o agente gere interfaces genéricas e sem identidade, inferindo a linguagem de design do projeto e ajustando variância, movimento e densidade da saída.

[Dê taste ao seu agente](https://github.com/Leonxlnx/taste-skill)

## Awesome Claude Skills

Lista curada de skills, recursos e ferramentas para personalizar fluxos de trabalho com Claude — especialmente Claude Code — organizada por categoria, com descoberta progressiva explicada.

[Percorra a lista curada](https://github.com/travisvn/awesome-claude-skills)

## i-have-adhd

Skill de formatação ADHD-friendly: dez regras que fazem o agente liderar com a próxima ação, numerar passos, estimar tempos concretos e eliminar preâmbulos — saída curta, escaneável e acionável.

[Instale o i-have-adhd](https://github.com/ayghri/i-have-adhd)
