## Lark CLI: Ferramenta Oficial para Automação com IA

**Descrição do input:** A imagem apresenta a lark-cli, ferramenta oficial da Lark (Feishu) para operacionalizar a plataforma via linha de comando. A ferramenta é mantida pelo time larksuite e foi construída para que tanto humanos quanto agentes de IA possam automatizar tarefas em 18 domínios de negócio, com mais de 200 comandos nativos e 26 habilidades estruturadas para agentes.

Principais destaques da imagem:
- Licença MIT, escrita em Go, versão 1.0.67 no npm
- Agent-Native Design: 24 habilidades estruturadas prontas para uso
- Wide Coverage: 18 domínios de negócio, 200+ comandos, 26 AI Agent Skills
- 3 minutos de setup inicial vs. dias de configuração tradicional
- Um único CLI para humanos e IAs (vs. integrações complexas de API)
- Input injection protection, terminal output sanitization, keychain nativo do SO

A automação corporativa foi transformada pela ferramenta.

[Acesse a fonte original](https://github.com/larksuite/cli)
