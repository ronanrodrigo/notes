## Remotion

Framework para criar vídeos de forma programática com React — o código é a fonte da verdade e o mesmo projeto serve para criação agêntica, edição interativa por drag and drop e renderização em lote na própria infraestrutura. Serve para automatizar vídeos repetitivos com templates e dados, uma base comum para serviços de edição short-form vendidos a agências de marketing e creators.

[Acesse o repositório do Remotion](https://github.com/remotion-dev/remotion)

## AutoClip

Ferramenta de clipping inteligente: analisa vídeos longos com IA, extrai highlights automaticamente, gera cortes e sugere coleções — com download e legendas do Bilibili, interface web em React e deploy via Docker. O repositório original do MVP foi descontinuado em favor do sucessor [zhouxiaoka/autoclip](https://github.com/zhouxiaoka/autoclip), que concentra as versões novas. Um bom exemplo de produto de extração de highlights para creators e streamers.

[Acesse o repositório do AutoClip MVP](https://github.com/zhouxiaoka/autoclip_mvp)

## OpenHands

O Agent Canvas do OpenHands é um centro de controle self-hosted para agentes de código: roda OpenHands, Claude Code, Codex, Gemini ou qualquer agente compatível com ACP em backends locais, remotos ou na nuvem, com automações agendadas e integrações com Slack, GitHub e Linear. Empacotado como serviço, vira uma oferta de "desenvolvedor autônomo" para pequenas e médias empresas.

[Acesse o repositório do OpenHands](https://github.com/OpenHands/OpenHands)

## PersonaLive

Framework de difusão em tempo real e streamável para animar retratos em vídeos de duração infinita, aceito no CVPR 2026. A partir de uma imagem de referência, gera animação facial expressiva para transmissões ao vivo — com inferência offline e online via WebUI, aceleração opcional com TensorRT e execução em 12 GB de VRAM. O projeto é liberado apenas para pesquisa acadêmica.

[Acesse o repositório do PersonaLive](https://github.com/GVCLab/PersonaLive)
