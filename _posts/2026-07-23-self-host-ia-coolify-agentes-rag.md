## Coolify
Self-host de apps (estilo Heroku/Vercel) com deploy via Git e auto-deploy.

[Acesse aqui](https://coolify.io/docs/applications/ci-cd/github/overview)

## OpenHands
Agentes para desenvolvimento de software que planejam e executam mudanças no códibase (controle por CLI/SDK).

[Acesse aqui](https://github.com/OpenHands/OpenHands)

## Open WebUI
Interface web "estilo ChatGPT" self-hosted para rodar localmente e conectar a modelos (inclui endpoints OpenAI-compatible e Ollama).

[Acesse aqui](https://github.com/open-webui/open-webui)

## Maxun
Plataforma no-code/open-source para extrair dados da web e transformar em dados estruturados/formatos como API/Markdown.

[Acesse aqui](https://github.com/getmaxun/maxun)

## Browser Use
Framework open-source para automação web por agentes (IA controlando navegação para executar tarefas online).

[Acesse aqui](https://github.com/browser-use/browser-use)

## Langflow
Editor visual open-source para orquestrar LLMs/fluxos (RAG e agentes) e expor como API.

[Acesse aqui](https://github.com/langflow-ai/langflow)

## Supabase
Backend tipo Firebase, mas em Postgres: Auth, Storage, Realtime e APIs automáticas (base para backends de apps).

[Acesse aqui](https://supabase.com/docs)

## Stirling PDF
Plataforma self-hosted open-source para editar/manipular PDFs (merge, split, OCR etc.) rodando localmente via Docker.

[Acesse aqui](https://github.com/Stirling-Tools/stirling-pdf)

## Crawl4AI
Crawler/scraper open-source "LLM-friendly" para gerar Markdown limpo e/ou extração estruturada em pipelines de RAG.

[Acesse aqui](https://github.com/unclecode/crawl4AI)

## Dify
Plataforma open-source para criar apps/agentes com workflows visuais, RAG e publicação via API; auto-hospedável.

[Acesse aqui](https://github.com/langgenius/dify)
