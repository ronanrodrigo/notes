## Happy

Cliente móvel e web para usar Claude Code e Codex à distância, com voz em tempo real e comunicação criptografada de ponta a ponta. O projeto oferece aplicativos para iOS e Android, uma aplicação web e um CLI que inicia os agentes no computador.

[Conheça o projeto no GitHub](https://github.com/slopus/happy)

## Documentação do Happy

Guia de uso, configuração e contribuição do ecossistema Happy, incluindo o aplicativo, o CLI, o agente remoto e o servidor de sincronização criptografada.

[Leia a documentação](https://happy.engineering/)

## Codex CLI

Agente de programação open-source da OpenAI que roda localmente no terminal. É a base de uma das experiências de agente que o Happy permite iniciar e controlar remotamente.

[Acesse o repositório oficial do Codex](https://github.com/openai/codex)

## Claude Code

Ferramenta agentic de programação da Anthropic que lê a base de código, edita arquivos, executa comandos e se integra ao fluxo de desenvolvimento no terminal, IDE, desktop e navegador.

[Consulte a visão geral oficial do Claude Code](https://code.claude.com/docs/en/overview)
