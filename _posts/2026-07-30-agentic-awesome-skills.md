## Agentic Awesome Skills

Biblioteca GitHub instalável de **skills agentic** (playbooks em `SKILL.md`) para assistentes de código como Claude Code, Cursor e Gemini CLI — pensada para colocar instruções de trabalho reutilizáveis no formato que cada ferramenta espera.

[Acesse a fonte original](https://github.com/sickn33/agentic-awesome-skills)

## Catálogo hospedado (para buscar e navegar)

Página hospedada para descobrir e explorar as skills a partir do conteúdo do repositório.

[Acesse a fonte original](https://sickn33.github.io/agentic-awesome-skills/)

## Instalação via `npx` e flags por assistente

Instalação prática com `npx agentic-awesome-skills`, com opções para direcionar o instalador ao ambiente/diretório do seu assistente (ex.: flags específicas por tool e `--path`).

[Acesse a fonte original](https://github.com/sickn33/agentic-awesome-skills)
