## Destaques

Real-time monitoring dashboard for Claude Code and Codex, built with SQLite3, Node.js, Express, React, Vite, TailwindCSS, and WebSockets. It tracks sessions, agent activity, tool usage, and subagent orchestration, providing live analytics, a Kanban status board, status notifications and an interactive web UI plus macOS and Windows native apps.
