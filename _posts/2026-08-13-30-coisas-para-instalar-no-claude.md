## 30 Things to Install into Claude

Compilação dos 30 repositórios e ferramentas recomendadas para expandir as capacidades do Claude Code.

## Harness — what it does before it types

Kategoria de extensões que melhoram o fluxo de trabalho antes da escrita de código.

* **superpowers** - Planos e debugs antes da escrita. [Repositório](https://github.com/anthropics/superpowers)
* **ECC** - Ajusta o harness inteiro para velocidade. [Repositório](https://github.com/anthropics/ecc)
* **karpathy-skills** - Uma CLAUDE.md derivada de Karpathy. [Repositório](https://github.com/karpathy/karpathy-skills)
* **gstack** - 23 ferramentas opinadas em um setup. [Repositório](https://github.com/gstack/gstack)
* **ponytail** - Diz nada, escreve uma linha. [Repositório](https://github.com/ponytail/ponytail)
* **learn-claude-code** - Um pequeno harness, construído para ler. [Repositório](https://github.com/anthropics/learn-claude-code)

## Skills — the jobs it repeats

Coleção de skills reutilizáveis que executam tarefas específicas.

* **anthropics/skills** - Biblioteca de skills própria da Anthropic. [Repositório](https://github.com/anthropics/anthropics-skills)
* **ui-ux-pro-max** - Paletas e fontes que funcionam. [Repositório](https://github.com/ui-ux-pro-max/ui-ux-pro-max)
* **taste-skill** - Faz uma página parecer cara. [Repositório](https://github.com/taste-skill/taste-skill)
* **awesome-claude-skills** - Lista curada de skills. [Repositório](https://github.com/awesome-claude-skills/awesome-claude-skills)
* **wshobson/agents** - Um marketplace de agentes prontos para usar. [Repositório](https://github.com/wshobson/agents)
* **claude-plugins** - Diretório próprio de plugins da Anthropic. [Repositório](https://github.com/anthropics/claude-plugins)

## Memory — what survives the session

Ferramentas para persistência e gerenciamento de contexto entre sessões.

* **graphify** - Transforma um codebase em um mapa. [Repositório](https://github.com/graphify/graphify)
* **claude-mem** - Mantém contexto em cada sessão. [Repositório](https://github.com/claude-mem/claude-mem)
* **codegraph** - Indexa seu código, sincroniza sozinho. [Repositório](https://github.com/codegraph/codegraph)
* **repomix** - Empaça um repositório inteiro em um arquivo. [Repositório](https://github.com/repomix/repomix)
* **planning-with-files** - Planejamento que sobrevive a um reinício. [Repositório](https://github.com/planning-with-files/planning-with-files)

## Tools — what it reaches past the terminal

Extensões que permitem Claude interagir com sistemas externos.

* **firecrawl** - Rastreia e extrai qualquer site limpo. [Repositório](https://github.com/mendableai/firecrawl)
* **cc-switch** - Alterna entre Claude, Codex e mais. [Repositório](https://github.com/cc-switch/cc-switch)
* **awesome-mcp-servers** - Cada servidor MCP listado. [Repositório](https://github.com/punkpeye/awesome-mcp-servers)
* **multica** - Atribui uma issue a vinte agentes. [Repositório](https://github.com/multica/multica)
* **claude-code-router** - Encaminha cada tarefa para o modelo certo. [Repositório](https://github.com/claude-code-router/claude-code-router)
* **playwright-mcp** - Deixa testar em um navegador real. [Repositório](https://github.com/mhnaumann/playwright-mcp)
* **github-mcp** - Lê e escreve GitHub. [Repositório](https://github.com/github/mcp-server-github)
* **vibe-kanban** - Um quadro para o que seus agentes estão fazendo. [Repositório](https://github.com/vibe-kanban/vibe-kanban)

## Cost — what it costs to run

Ferramentas para monitoramento e otimização de custos.

* **system-prompts-ai** - Os prompts de sistema reais, coletados. [Repositório](https://github.com/system-prompts-ai/system-prompts-ai)
* **caveman** - As mesmas respostas, bem menos tokens. [Repositório](https://github.com/caveman/caveman)
* **best-practice** - Vibes de engenharia para agentes. [Repositório](https://github.com/best-practice/best-practice)
* **codex-plugin-cc** - Roda Codex dentro do Claude Code. [Repositório](https://github.com/codex-plugin-cc/codex-plugin-cc)
* **claude-hud** - Mostra o consumo antes de ele cair. [Repositório](https://github.com/claude-hud/claude-hud)
