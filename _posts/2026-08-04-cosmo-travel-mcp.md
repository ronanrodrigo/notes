## Cosmo Travel MCP Server

Servidor MCP com onze ferramentas de viagem para busca de voos, reservas de acomodações e planejamento de itinerários. Utiliza dados comerciais licenciados do SerpAPI e Google Maps. Inclui suporte a voos one-way/round-trip, itinerários multi-cidade, detalhes de hotéis, busca de eventos, comparação drive vs fly e skill "plan-a-trip".

[Acesse a fonte original](https://github.com/maththedev42/cosmo-travel-mcp)

## MCP Travel Assistant Suite

Conjunto de seis servidores MCP especializados que permite a um LLM orquestrar buscas de voos, hotéis, eventos, clima, geolocalização e finanças para gerar itinerários completos de viagem.

[Acesse a fonte original](https://github.com/skarlekar/mcp_travelassistant)

## Flights MCP Server

Servidor MCP genérico para planejamento de viagens complexas com ferramentas de busca de voos via Booking.com API, hotéis e aluguel de carros.

[Acesse a fonte original](https://github.com/prakashsanker/flights-mcp-server)

Artigo que explica como o Model Context Protocol permite que agentes de IA acessem dados em tempo real de sistemas de hotéis, companhias aéreas e OTAs sem integrações customizadas.
