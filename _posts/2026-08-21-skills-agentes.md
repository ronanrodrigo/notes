## Pedro Nauck's Skills

Coleção pessoal de 131 skills para Claude Code e assistentes de programação compatíveis. O repositório reúne skills originais, projetos selecionados da comunidade e materiais voltados a marketing, negócios e escrita, com instalação rápida via `npx skills add` ou instalação por categoria e skill individual.

[Explore a coleção no GitHub](https://github.com/pedronauck/skills)

## Agent Skills Specification

Especificação aberta que define o formato portátil de uma skill: uma pasta com `SKILL.md`, front matter YAML e instruções em Markdown, podendo incluir scripts, referências e assets. O documento também descreve descoberta progressiva, organização de recursos e validação com `skills-ref`.

[Leia a especificação completa](https://github.com/agentskills/agentskills/blob/main/docs/specification.mdx)

## Anthropic Skills

Repositório público com exemplos de skills para aplicações criativas, tarefas técnicas, fluxos corporativos e edição de documentos. É uma referência prática para observar skills autocontidas, padrões de `SKILL.md` e formas de distribuição por plugins no Claude Code.

[Consulte os exemplos oficiais](https://github.com/anthropics/skills)
