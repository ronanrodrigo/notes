## Spell UI: componentes React animados prontos para copiar

Coleção de componentes reutilizáveis para React e Tailwind, com visual refinado e animações prontas: Light Rays com shaders WebGL, Animated Gradient, Tilt Card 3D, Pop Button, Exploding Input, Spotify Card. Distribuídos via registry shadcn em spell.sh, com preview interativo, código TSX e instalação pela CLI. Repositório aberto sob licença MIT.

[Acesse a fonte original](https://spell.sh/docs)

## Refero Styles: design systems de produtos reais em DESIGN.md

Biblioteca com mais de 2.000 design systems extraídos de sites reais de produto, empacotados como arquivos DESIGN.md legíveis por agentes de IA. Cada estilo traz cores, tipografia, espaçamento, componentes e regras de uso, prontos para colar no contexto de Cursor, Claude Code, Codex, v0 ou Lovable. Também oferece MCP com telas reais e fluxos de usuário para o agente pesquisar antes de gerar a interface.

[Acesse a fonte original](https://styles.refero.design/)

## Inspora: arquivo curado de design visual

Arquivo de referências visuais com curadoria manual, atualizado com frequência, reunindo trabalhos recentes de web design, branding, produto, motion, ilustração e 3D. Cada entrada mostra um projeto com seus destaques visuais e filtro por categoria. Alternativa leve e sem anúncios ao feed de redes sociais para acompanhar tendências e coletar referências.

[Acesse a fonte original](https://www.inspora.design/)
